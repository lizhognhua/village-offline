==============================================
  驻村帮扶管理系统 V1.2 — 安装须知
==============================================

【安装步骤】

  第一步：运行「系统自检.bat」
     → 脚本会自动检测磁盘空间、端口、内存
     → 生成「安装建议.txt」报告

  第二步：按照安装建议移动文件夹
     → 示例：将 village-system-v1.2 移到 D:\ 目录
     → 路径不要包含中文或空格

  第三步：双击「启动系统.bat」
     → 首次运行自动创建数据库（约30秒）
     → 浏览器自动打开系统页面

  第四步：登录系统
     → 默认账号：admin
     → 默认密码：admin123
     → 登录后建议立即修改密码

==============================================

【局域网共享使用】

  本系统支持同一 WiFi/网线下多人共用：

  主机（运行程序的电脑）：
     → 双击「启动系统.bat」
     → 首次弹出防火墙提示请点击「允许访问」

  队员电脑（同一网络下的其他电脑）：
     → 打开浏览器
     → 输入启动窗口中显示的地址
     → 格式：http://192.168.x.x:3000
     → 登录即可使用（与主机共用数据）

  注意：
     → 主机电脑关机后系统停止，队员无法访问
     → 三人共用同一套数据（农户档案、走访记录等）
     → 数据存储在主机 data\ 文件夹中

==============================================

【数据备份与恢复】（V1.2 新增）

  方法一：系统内置一键备份（推荐）
     → 登录系统 → 系统设置 → 数据备份
     → 点击「一键备份」→ 浏览器自动下载 .zip 文件
     → 备份包含：数据库 + 全部上传文件/照片

  方法二：手动备份
     → 关闭系统（关闭命令行窗口）
     → 找到系统文件夹下的 data\ 目录
     → 将整个 data 文件夹复制到其他位置保存（U盘等）

  恢复数据：
     → 方法一（内置）：系统设置 → 数据备份 → 选择备份 .zip → 确认恢复
     → 方法二（手动）：关闭系统 → 将备份的 data 文件夹复制回系统目录覆盖
     → 恢复后需重启系统生效

【注意事项】

  1. 请勿将文件夹放在 C: 盘临时目录或桌面深层
     推荐位置：D:\village-system-v1.2\

  2. 首次启动 Windows 防火墙会弹出安全提示
     请务必点击「允许访问」，否则局域网无法使用

  3. 定期备份数据（建议每周一次）
     推荐使用系统内置「数据备份」功能

  4. 系统更新
     下载新版本压缩包 → 解压到新位置
     将旧 data\ 文件夹复制到新版本目录即可保留数据
     或使用「恢复数据」功能导入备份

  5. 修改密码
     登录系统后 → 系统设置 → 可添加或删除用户

【常见问题】

  Q: 启动后浏览器没有自动打开？
  A: 手动打开浏览器，地址栏输入 http://localhost:3000

  Q: 队员电脑输入IP地址后打不开？
  A: ①确认主机和队员在同一WiFi
      ②检查主机防火墙是否允许了端口3000
      ③确认输入的IP地址与启动窗口显示的完全一致

  Q: 提示端口已被占用？
  A: 可能有其他程序占用了3000端口，重启电脑后再试

  Q: 忘记密码怎么办？
  A: 删除 data\village.db 文件后重新启动
     系统会自动重建数据库（原有数据会丢失）

  Q: 如何备份数据？
  A: 登录系统 → 系统设置 → 数据备份 → 一键备份
     或手动复制 data\ 文件夹到安全位置
