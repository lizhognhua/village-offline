==============================================
  驻村帮扶管理系统 — 安装须知
==============================================

【安装步骤】

  第一步：运行「系统自检.bat」
     → 在解压后的文件夹根目录中
     → 脚本会自动检测磁盘空间、端口、内存
     → 生成「install-guide.txt」报告

  第二步：按照安装建议移动整个文件夹
     → 示例：将解压后的文件夹移到 D:\ 目录
     → 路径不要包含中文或空格

  第三步：双击「启动系统.bat」
     → 位于解压后的文件夹根目录中
     → 首次运行自动创建数据库（约30秒）
     → 浏览器自动打开系统页面

  第四步：登录系统
     → 默认账号：admin
     → 默认密码：admin123
     → 登录后建议立即修改密码

==============================================

【局域网多用户共用】

  本系统支持同一 WiFi/网线下多人共用：

  主机（运行程序的电脑）：
     → 双击「启动系统.bat」
     → 首次弹出防火墙提示请点击「允许访问」

  队员电脑（同一网络下的其他电脑）：
     → 打开浏览器
     → 输入启动窗口中显示的地址
     → 格式：http://192.168.x.x:3000
     → 登录即可使用（与主机共用数据）

  注意：
     → 主机电脑关机后系统停止，队员无法访问
     → 数据存储在主机 data\ 文件夹中
     → 队员不需要下载软件，浏览器打开即可
     → 所有数据只有一份，不会冲突

  简单理解：
    谁运行「启动系统.bat」，数据就在谁电脑上。
    只有一台电脑需要运行系统，其他人都用浏览器访问。

==============================================

【管理员与队员权限说明】

  管理员（admin 账号）：
     → 可使用系统全部功能
     → 管理队员账号（系统设置 → 队员管理）
     → 修改系统设置、村情概况、屯组
     → 管理备份和系统升级
     → 录入走访、日记、产业等所有日常数据

  队员（普通账号）：
     → 录入走访记录、慰问记录、工作日记
     → 录入产业、项目、党建活动
     → 管理家庭农户信息
     → 上传文件和照片
     → 查看所有数据
     → 不可修改系统设置
     → 不可管理其他队员账号

  如何添加队员账号：
     1. 管理员登录 → 系统设置 → 队员管理 → 添加队员
     2. 目前需要联系技术支持帮队员创建登录账号
     （后续版本将支持管理员直接在页面上创建队员账号）

【数据备份与恢复】

  方法一：系统内置一键备份（推荐）
     → 登录系统 → 系统设置 → 数据备份
     → 点击「一键备份」→ 浏览器自动下载 .zip 文件
     → 备份包含：数据库 + 全部上传文件/照片

  方法二：手动备份
     → 关闭系统（关闭命令行窗口）
     → 找到系统文件夹下的 data\ 目录
     → 将整个 data 文件夹复制到其他位置保存（U盘等）

  恢复数据：
     → 登录系统 → 系统设置 → 数据备份 → 选择备份文件 → 恢复
     → 或手动将备份的 data 文件夹复制回系统目录覆盖

==============================================

【在线升级】

  登录系统后，仪表盘顶部会自动检测新版本
  发现新版本后点击「在线升级」即可自动完成升级
  升级前系统会自动备份数据

==============================================

【注意事项】

  1. 请勿将文件夹放在 C: 盘临时目录或桌面深层
     推荐位置：D:\

  2. 首次启动 Windows 防火墙会弹出安全提示
     请务必点击「允许访问」，否则局域网无法使用

  3. 定期备份数据（建议每周一次）

  4. 系统更新
     下载新版本压缩包 → 解压到新位置
     将旧 data\ 文件夹复制到新版本目录即可保留数据

  5. 修改密码
     登录系统后 → 系统设置 → 可添加或删除用户

【常见问题】

  Q: 启动后浏览器没有自动打开？
  A: 手动打开浏览器，地址栏输入 http://localhost:3000

  Q: 队员电脑输入IP地址后打不开？
  A: 确认识主机和队员在同一WiFi
      检查主机防火墙是否允许了端口3000
      确认输入的IP地址与启动窗口显示的完全一致

  Q: 提示端口已被占用？
  A: 可能有其他程序占用了3000端口，重启电脑后再试

  Q: 忘记了密码？
  A: 删除 data\village.db 文件后重新启动
     系统会自动重建数据库（原有数据会丢失）

  Q: 如何备份数据？
  A: 登录系统 → 系统设置 → 数据备份 → 一键备份
     或手动复制 data\ 文件夹到安全位置

  Q: 系统自检.bat 双击后消失了？
  A: 右键点击 → 以管理员身份运行
     如果仍然消失，说明系统不支持PowerShell或被杀毒软件拦截
