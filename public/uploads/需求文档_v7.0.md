# 需求文档 v7.0

> 版本：v0.2.0 | 2026年5月 | 系统 v3 镜像 | Next.js 14 + PostgreSQL 16

## 一、系统架构（当前）

```
公网:222.171.139.234
  ├── 8000  → village-app v3 (Next.js 驻村管理系统)
  ├── 8005  → paperless-web (Paperless-ngx 文档管理系统)
  ├── 8006  → planka (Planka 项目看板)
  ├── 8061  → siyuan (思源笔记)
  ├── 8081  → village-lsky (兰空图床 Lsky Pro)
  ├── 8082  → showdoc (ShowDoc 知识库)
  └── 其他   → 站长工具、音乐、记账等
```

### 数据库

- **PostgreSQL 16**（独立 Container，端口 5432）
- **主库**: `village-db` — 驻村帮扶管理系统全部业务数据（20+张表）
- **独立库**: `planka` — Planka 看板独立数据库

## 二、本轮迭代需求（P0-P2）

### P0 — 核心功能升级

#### ① 项目看板 — Planka 部署对接

- **新增服务**: Planka 开源看板（端口 8006）
- **对接方式**: 侧边栏「任务看板」新窗口打开
- **数据库**: 独立 PostgreSQL 数据库 `planka`
- **默认账号**: admin / 初始密码
- **状态**: ✅ 已完成

#### ② 档案管理 — Paperless 集成

- **对接服务**: Paperless-ngx（端口 8005）
- **新数据模型**: `ArchiveDoc`（docId、title、category、tags、correspondent、url）
- **功能实现**:
  - 档案概览页：统计卡片（总文档数/本月新增/总分类数）
  - 电子文档列表：从 Paperless API 获取文档列表（标题/分类/标签/日期）
  - 档案录入：通过 Paperless API 上传文件+元数据
  - Paperless 内嵌页面入口
- **状态**: ✅ 已完成

#### ③ 走访记录 — 图片上传 + 状态标签

- **模型升级**: `Visit` 新增 `statusTags` 字段（JSON 字符串，如 `["在家","健康"]`）
- **状态标签选项**: 5个固定标签

| 标签 | 说明 |
|:----:|:----:|
| 在家 | 农户在家 |
| 外出务工 | 外出务工不在家 |
| 出门 | 临时出门 |
| 健康 | 身体状况良好 |
| 生病 | 身体不适/生病 |

- **图片上传**: 走访记录可附带图片（存 `/app/public/uploads/`）
- **前端实现**:
  - 新建走访表单：图片多选预览（PreviewFile 组件）+ 状态标签 CheckboxGroup
  - 走访详情页：状态标签展示
  - 走访列表页：标签筛选
- **上传API**: `POST /api/visits/upload`
- **状态**: ✅ 已完成

#### ④ 慰问记录 — 图片上传 + 经办人多选

- **模型升级**: `Condolence` 新增 `imageUrls` 字段（JSON 字符串数组）
- **经办人选项**: 10个固定选项

| 选项 | 说明 |
|:----:|:------|
| 局领导 | 机关事务管理局领导 |
| 县领导 | 县级领导 |
| 乡领导 | 乡级领导 |
| 肖慧军 | 驻村工作队队长 |
| 李中华 | 驻村工作队员 |
| 马威 | 驻村工作队员 |
| 村委会 | 村委会成员 |
| 屯组长 | 屯/组长 |
| 医疗行业 | 医疗行业代表 |
| 民政 | 民政部门人员 |

- **图片上传**: 慰问记录可附带图片
- **前端实现**:
  - 新建慰问表单：图片多选预览 + 经办人多选 CheckboxGroup
  - 慰问列表页：缩略图预览（3列网格）
  - 经办人标签展示
- **状态**: ✅ 已完成

### P1 — 功能补全

#### ⑤ 经办人多选（统一实现）

- **范围**: 慰问记录、走访记录等相关页面
- **存储**: 逗号分隔字符串存储
- **前端**: CheckboxGroup 组件，10个选项勾选
- **状态**: ✅ 已完成

#### ⑥ 主页日记计数修复

- **问题**: Dashboard 日记计数原显示为硬编码 3条
- **修复**: 改为从数据库查询真实日记数量
- **状态**: ✅ 已完成（数据库中有3篇：2篇思源同步+1篇手动，列表受权限过滤）

#### ⑦ 产业管理 — 增删改查

- **新数据模型**: `Industry`（id、name、status、scale、description、details、benefits、imageUrl、createdAt、updatedAt）
- **API**:
  - `GET/POST /api/industries` — 列表/新建
  - `GET/PUT/DELETE /api/industries/[id]` — 详情/编辑/删除
- **前端实现**:
  - 产业卡片列表页（卡片布局，含图片+状态+规模）
  - 新建产业弹窗
  - 产业详情弹窗
  - 支持产业图片
- **状态**: ✅ 已完成

### P2 — 体验优化

#### ⑧ 全局导航优化 — 面包屑导航

- **组件**: `Sidebar.tsx` 集成面包屑导航
- **显示**: 当前位置路径（如 首页 > 走访记录 > 新建走访）
- **样式**: 深色主题风格，侧边栏顶部固定显示
- **状态**: ✅ 已完成

## 三、数据模型变更（v6.0 → v7.0）

### 新增字段

| 模型 | 字段 | 类型 | 说明 |
|:----|:----|:----:|:-----|
| Visit | statusTags | String (JSON) | 走访状态标签数组 |
| Condolence | imageUrls | String (JSON) | 慰问图片URL数组 |

### 新增模型

| 模型 | 字段 | 关联 |
|:----|:-----|:----:|
| Industry | id, name, status, scale, description, details, benefits, imageUrl, createdAt, updatedAt | 无关联（独立） |
| ArchiveDoc | id, docId, title, category, tags, correspondent, url, fileType, pageCount, createdAt, updatedAt | 无关联（Paperless映射） |
